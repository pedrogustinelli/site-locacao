# 🚛 Site de Locação de Caminhões e Caçambas

Site institucional desenvolvido para apresentar os serviços de locação de caminhões e caçambas, permitindo que os clientes conheçam a empresa, visualizem os equipamentos disponíveis e entrem em contato de forma rápida e prática.

## ✨ Funcionalidades


* Apresentação da empresa;
* Exibição dos caminhões e caçambas;
* Informações sobre os serviços;
* Botão para contato via WhatsApp;
* Design responsivo para computadores e dispositivos móveis.

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
